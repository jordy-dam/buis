# Onboarding — index

> Goal: be productive in 5 minutes, no verbal briefing.

Pick the file that matches who you are:

- New human developer → `new-dev.md`
- New AI agent picking up this repo → `new-agent.md`

Do NOT read both unless you genuinely need to. Choose one.

## Read / Write contract
- **Read:** once, at the start — when you (human or agent) are new to this repo.
- **Write:** when onboarding steps go stale (setup command changed, a step is now wrong). Whoever hits the friction fixes the file.
- **When:** rarely. This is the most stable folder — if you're editing it often, something deeper is churning.
- **How:** keep it to the 5-minute path. Resist turning it into full docs; deep knowledge belongs in `docs/`.
