# 2026-10-28 — Phase 1: works on my tv

Status: **built and emulator-verified; real-tv test pending.** Branch `feat/phase-1`.

## Architecture (as built)
One `:app` module plus a dev-only `:mockserver` (JVM, never in the APK).

```
app/src/main/kotlin/nl/jordy/iptv/
  data/xtream/  XtreamClient (OkHttp, streaming arrays), XtreamParser (defensive), StreamUrls
  data/db/      Room: catalog (generation-stamped), episodes, favourites, playback positions
  data/sync/    CatalogSync: stream-decode → batches of 500 → drop older generation
  data/auth/    CredentialStore: DataStore + Tink AEAD, Keystore-wrapped key
  data/repo/    EpgRepository (short EPG, 5-min cache), LibraryRepository (info, favourites, resume)
  player/       PlayerViewModel (one ExoPlayer), LiveSources (hls → ts), ResumePolicy, FailFastLoadErrorPolicy
  ui/           theme, components, login, sync, shell (rail), live, vod, detail, favorites, player
```

Screen flow: Login → Sync → Shell (rail: Live TV · Films · Series · Favorieten) → Detail → Player.
Back: player → detail → list → Live TV → "Afsluiten?".

## How it was tested
- 28 unit tests: parsing against the messy fixtures, 12k-item sync, re-sync, empty-answer guard,
  resume boundaries, hls → ts fallback, fail-fast policy. `./gradlew test` + `./gradlew lint` green.
- Every screen walked with the d-pad only on the Google TV emulator (1080p) via `adb input keyevent`,
  checking focus with screenshots and the accessibility tree. Bugs found and fixed that way: focus
  entering the wrong category, Right at a row end jumping to another row, Down on detail buttons
  jumping sideways, series detail overflowing the 540dp screen, 3s+ zap on TS-only channels.

## Known limitations
- Only tested against the mock server; real providers may differ (redirects, user-agent checks, 429s).
- Positions are saved every 10s and on pause/stop/exit: a crash can lose up to 10s.
- Catalog re-syncs at launch when older than 24h, or by hand under Instellingen.
- APK is ~49 MB, mostly the FFmpeg libraries for two ARM ABIs.
- Room uses destructive migrations: fine while it's a cache, must change before phase 2 stores
  per-profile history.

## What Jordy tests on the real tv
1. Install: on the tv, enable developer options and wireless debugging, then
   `adb pair <tv-ip>:<pair-port>`, `adb connect <tv-ip>:<port>`, `./gradlew installDebug`.
2. Log in with the real subscription; note how long the sync takes.
3. Zap through a category with ↑/↓; it should feel instant to ~1s. If not: `adb logcat -s Zap`.
4. Play a film for a minute, press Home, reopen, and check "Hervatten". Then reboot the tv and check again.
5. Find a channel with AC3/EAC3 audio (often sports or film channels) and check for sound.
6. Long-press OK on a channel and a film; check both appear under Favorieten.
